# محاسبه‌گر برق خانگی ۱۴۰۵ — Android نسخه ۱٫۱

## امکانات نسخه جدید
- تب‌های بالای صفحه: ورود اطلاعات، نتیجه دوره، نحوه محاسبه و جدول پله‌ای.
- شرح فرمول‌ها با جایگذاری مقادیر واقعی: قرائت جاری − قبلی، مصرف معادل ۳۰روزه، شمارش روزهای گرم/سرد، ضریب وزنی، بهای ماهانه و بهای دوره.
- جدول پله‌ای با مبلغ هر پله برای ۳۰ روز و سهم همان پله از کل بهای دوره. در دوره ترکیبی، سهم هر ردیف با تعداد روزهای بخش گرم یا سرد تعدیل می‌شود.
- تب «نحوه محاسبه» توضیح می‌دهد برای دوره کاملاً سرد فقط جدول غیرگرم و برای دوره کاملاً گرم فقط جدول گرم استفاده شده است؛ در دوره ترکیبی، هر قسمت جدا محاسبه می‌شود.
- چاپ/ذخیره PDF با سرویس چاپ بومی Android: دکمه «چاپ / ذخیره PDF» پنجره چاپ سیستم را باز می‌کند. در آن پنجره گزینه «Save as PDF / ذخیره به‌صورت PDF» را انتخاب کنید.
- هیچ کتابخانه خارجی در زمان اجرا لازم نیست؛ رابط با WebView و منطق برنامه در فایل محلی HTML اجرا می‌شود.

## ساخت APK بدون Android Studio
این پروژه Workflow مربوط به GitHub Actions دارد: `.github/workflows/build-apk.yml`. با قرار دادن پروژه در مخزن GitHub و اجرای **Actions → Build APK → Run workflow**، فایل APK به‌عنوان Artifact با نام `electricity-1405-apk` در بخش Artifacts دانلود می‌شود.

## ساخت با Android SDK محلی
با Gradle و Android SDK نصب‌شده، از پوشه پروژه اجرا کنید:

```bash
gradle :app:assembleDebug
```

APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکته درباره مبلغ
محاسبه‌گر بهای انرژی را بر اساس جدول‌های داخلی برنامه محاسبه می‌کند. مالیات، عوارض، سوخت نیروگاهی، بیمه و ردیف‌های دیگر قبض ممکن است جداگانه محاسبه شوند؛ بنابراین مبلغ انرژی لزوماً برابر مبلغ نهایی قبض نیست.
