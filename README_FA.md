# محاسبه‌گر برق خانگی ۱۴۰۵ — نسخه Android

این پروژه نسخه اندروید همان محاسبه‌گر برق است و منطق روزهای گرم/سرد را از تاریخ واقعی دوره محاسبه می‌کند.

## ویژگی‌ها
- انتخاب استان و شهر/شهرستان از فهرست موجود
- تشخیص منطقه گرمسیر ۱ تا ۴ از روی قواعد زمانی شهر
- محاسبه تعداد روزهای گرم و سرد بر اساس تاریخ دوره
- دوره کاملاً سرد => فقط تعرفه سرد/غیرگرم
- دوره کاملاً گرم => فقط تعرفه گرم
- دوره ترکیبی => تفکیک گرم/سرد
- جدول تفکیکی مصرف و پله‌های تعرفه
- بدون کتابخانه جانبی در زمان اجرا؛ فقط Android WebView

## ساخت APK
پروژه را در Android Studio باز کنید. پس از Sync:

Build > Build APK(s)

یا در ترمینال پروژه:

`./gradlew assembleDebug`

APK در این مسیر ساخته می‌شود:

`app/build/outputs/apk/debug/app-debug.apk`

این محیط فعلی Android SDK / build-tools را ندارد، بنابراین فایل APK باینری از داخل این محیط ساخته نشده است؛ پروژه Android آماده Build تحویل داده شده است.
