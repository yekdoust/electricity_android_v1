محاسبه‌گر برق خانگی ۱۴۰۵ — نسخه ۱٫۱

روش پیشنهادی بدون Android Studio:
1) پوشه پروژه را به مخزن GitHub خود ارسال کنید.
2) در GitHub به تب Actions بروید.
3) Workflow با نام Build APK را انتخاب کنید و Run workflow را بزنید.
4) بعد از پایان موفق، در پایین صفحه اجرای Workflow بخش Artifacts، فایل electricity-1405-apk را دانلود کنید.
5) ZIP مربوط به Artifact را باز کنید تا app-debug.apk را دریافت کنید.

ساخت محلی با Android SDK و Gradle:
gradle :app:assembleDebug

خروجی:
app\build\outputs\apk\debug\app-debug.apk

برای خروجی PDF داخل اپ، دکمه «چاپ / ذخیره PDF» پنجره چاپ سیستمی Android را باز می‌کند؛ سپس «Save as PDF / ذخیره به‌صورت PDF» را انتخاب کنید.
